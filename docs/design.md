# Design

## Information hierarchy
1. 제목과 짧은 설명
2. HTML 입력 영역과 점검 버튼
3. 결과 요약 카드(통과/오류/경고/통과 항목)
4. 문제 목록: 심각도 배지, 요소 맥락, 해결 안내

## Interaction
초기 예제 HTML을 제공한다. 버튼 클릭 또는 입력 폼 제출 시 결과를 갱신한다. 결과 영역은 `aria-live="polite"`로 알린다.

## Responsive and accessibility
한 열 레이아웃을 기본으로 하고 넓은 화면에서 입력과 결과를 두 열로 배치한다. 색만으로 심각도를 구분하지 않으며 텍스트 배지를 함께 쓴다. 충분한 대비, 키보드 초점, 명시적 폼 레이블을 제공한다.
